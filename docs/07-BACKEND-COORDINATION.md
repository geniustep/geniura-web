## تحديث العقد بعد إصلاح CSRF (2026-10-18)
- آخر Backend مختبر: `4d8472c`، ويعيد `csrf_failed` في الاستجابات المرفوضة، بينما `GET /api/v1/auth/csrf` يعيد رمزًا مقنّعًا داخل JSON.
- **أُنجز** تحديث عقد الواجهة وملفات Orval إلى Backend `4d8472c3`، مع الاحتفاظ بالاستبعادات
  الأمنية وتصحيحات الأغلفة القديمة بعد التحقق من استمرار الحاجة إليها.
- بعد مزامنة العقد يجب إزالة تصحيحات pagination/vocabulary **فقط** إذا أصبح Backend نفسه يصف الأغلفة بدقة؛ لا تُحذف دون دليل.
- يجب التأكد من استبعاد عملية تنزيل وثائق التحقق الموسومة `Trust (staff)` ولو لم يكن مسارها تحت `/staff/`.
- مصادقة الصفحات الخاصة تتطلب حلًا معتمدًا لـCookie الجلسة أو BFF؛ هذا العمل ليس تخويلًا لتوسيع Cookie للجلسة أو نشر Staging.
