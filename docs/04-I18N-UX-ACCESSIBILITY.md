# اللغات، المصطلحات، وإتاحة الوصول

## مبادئ اللغات
- المشروع يستهدف أربع لغات واجهة؛ لم تُعتمد قائمتها النهائية في الورقة، فلا تفترض أسماء الأربع أو تبنِ واجهة تفرضها قبل قرار معتمد.
- يُصمم النظام بتعدد اللغات منذ البداية؛ RTL عند استعمال العربية ولغات RTL، وLTR حسب اللغة والنص.
- تفضيل المستخدم محفوظ؛ لغة الواجهة منفصلة عن اللغة الأصلية لإعلان الوظيفة ولغات إتقان الوظيفة.
- البحث يفهم المقابلات والمرادفات المحلية دون دمج مهن مختلفة تعسفًا.
- لا تعد بترجمة بشرية لجميع الإعلانات؛ اعرض اللغة الأصلية ووسم أي ترجمة آلية.
- لا تُترجم المعرّفات والرموز الثابتة وقيم حالات API؛ ترجم النصوص المرئية فقط.
- فرنسية/عربية مثالان واردان بالورقة لا يمثلان موافقة نهائية على ترتيب الأربع لغات.

## جودة UX
- Mobile-first، بحث سريع، حقول ضرورية فقط عند أول ترشح، فلاتر متقدمة مطوية افتراضيًا.
- وضوح حالات التحميل والخطأ والنجاح؛ عدم إيهام الباحث بأن طلبه قُرئ دون دليل.
- الوصول بلوحة المفاتيح، تسميات صحيحة للحقول، تباين مناسب، رسائل أخطاء قابلة للفهم، وإسناد الاتجاه لكل حقل متعدد اللغات.
- تجنب الفرز أو الرفض الآلي غير المفسَّر. لا تقدم تدريبًا مدفوعًا كشرط للتوظيف.
- قياس تجربة الباحث والشركة من خلال إكمال الترشح ومعدلات الاستجابة لا مجرد عدد الزيارات.
