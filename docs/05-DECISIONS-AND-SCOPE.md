# سجل القرارات — Geniura Web

## معتمد من النقاش
- لغات الواجهة الأربع (2026-10-18): العربية `ar` (افتراضية)، الفرنسية `fr`، الإنجليزية `en`، الإسبانية `es`.
- العلامة: Geniura والنطاق geniura.com.
- نموذج هجين: وظائف مفتوحة، انتقاء/تقييم احترافي، وتأهيل مرتبط بسوق العمل.
- مستودع الواجهة عام: geniustep/geniura-web؛ المستودع الخلفي خاص: geniustep/geniura-api.
- Next.js + TypeScript للواجهة؛ Django + PostgreSQL للنظام الخلفي؛ لا Odoo لهذا المشروع.
- التنفيذ اليوم الحالي وثائق فقط؛ لا كود، ولا إعداد تشغيل، ولا نشر.
- الأولوية لتجربة بسيطة، والحفاظ على خصوصية الملفات والمؤسسات، ومجانية الترشح.
- سياسة Git المفضلة: main وdev فقط للعمل اليومي؛ مراجعة وموافقة واضحة قبل الإنتاج.

## مقترحات فنية قيد التنفيذ لاحقًا
نمط modular monolith؛ REST API /api/v1؛ OpenAPI؛ تقييم قائم على الأدلة؛ فهرسة تقليدية أولًا وpgvector لاحقًا؛ تطبيق هاتف لاحقًا إن لزم؛ CI واختبارات عقد.

## قرارات تحتاج اعتمادًا قبل الإطلاق
المدينة والقطاعات الأولى؛ مزود الهوية والبريد؛ نموذج الجلسات وCSRF وفق النشر؛ التسعير والدفع؛ القنوات المسموحة؛ سياسة مشاركة CV؛ مدد الاحتفاظ؛ إجراءات CNDP والترخيص القانوني؛ معايير جاهزية سوق التوظيف والمراجعة.
لا تملأ الفراغات بقرارات تجارية أو قانونية مختلقة.

## قواعد العمل
- لا تغيير على المستودع الخلفي من وكيل الواجهة، والعكس إلا بتكليف محدد.
- لا رفع أسرار أو بيانات مرشحين أو صور هويات إلى المستودع العام.
- مراحل التوثيق والتصميم منفصلة عن التنفيذ؛ مرحلة السيرفر ستكون لوكيل منفصل بعد موافقة.
- كل واجهة تستخدم عقد API معتمدًا؛ التغييرات تُوثّق في كلا الطرفين.
