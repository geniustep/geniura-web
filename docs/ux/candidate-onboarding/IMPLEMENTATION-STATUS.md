# رحلة بدء الملف المهني — 31 أكتوبر 2026

## المنفذ في الواجهة
- زر «أنشئ ملفك المهني» يفتح `/[locale]/start`، مع عرض اختيار إضافة CV أولًا، والإدخال اليدوي بديلًا.
- عند اختيار رفع/إدخال يدوي بلا جلسة، تظهر خطوة دخول/تسجيل صادقة، تحفظ `next` في التنقل بين النموذجين وعند الرجوع من نتيجة التسجيل.
- المسجّل يعود إلى الرفع أو الإدخال اليدوي وفق اختياره. الرفع يستعمل ResumesPanel القائم، الذي يراقب الفحص والاستخراج ويفتح المراجعة عند الجاهزية فقط. لا اعتماد تلقائي للمعلومات.
- ترحيب باسم الحساب المثبت، مع عرض مراجعة معلقة عند وجودها. لا يُستنتج الاسم من اسم الملف.
- اللغات ar/fr/en/es؛ noindex وprivate,no-store لشاشة البدء. لا تغييرات في الأذون أو الفهرسة العامة.

## ما لم يُنفذ بعد
هذا تنفيذ مرحلي صالح للمسار الحالي، وليس تنفيذًا كاملًا لمسار الضيف المعتمد. لا رفع أو استخراج قبل تسجيل الدخول، ولا استخراج اسم/بريد/هاتف للترحيب، ولا دخول دون كلمة مرور.

## الفجوة المثبتة في Django
`Resume.profile` مطلوب ويرتبط بالمستخدم. `UploadIntentView` يستعمل `get_or_create_profile(request.user)`؛ ومسارات الاستخراج/المراجعة تتحقق من المالك. `ExtractedItem.Kind` لا يحتوي هوية الشخص أو وسائل الاتصال. خدمات المصادقة الحالية: بريد/كلمة مرور، تأكيد البريد، واسترجاع كلمة المرور؛ لا endpoint لمسودة ضيف أو ربطها أو توجيه الحساب بعد إثبات البريد. لا يجوز حل ذلك بحساب مستخدم مشترك أو رفع عام غير محمي.

## العقد المطلوب للمرحلة التالية (اقتراح، غير موجود في API)
1. مسودة ضيف مستقلة عن CandidateProfile، مع معرّف عشوائي وجلسة HttpOnly مرتبطة بها؛ لا معرفات اتصال في URL أو logs.
2. انتهاء صلاحية محدود (مقترح 24 ساعة)، وحذف الملفات والاستخراج عند الانتهاء؛ مع أمر تنظيف وتشغيل دوري واختبار الحذف الفعلي.
3. استعمال نفس حجر الملفات والفحص وحدود 5 MiB وPDF/DOCX؛ تحديد معدل وحصة لكل جلسة وللمصدر، ومنع استنزاف خدمة الاستخراج. لا توسيع المسارات المحمية الحالية إلى AllowAny.
4. الاسم والبريد والهاتف اقتراحات غير موثقة قابلة للتعديل؛ الاسم لا يثبت الهوية، وعدم وجوده لا يعطل المسار. لا حفظ تلقائي في الحساب.
5. تأكيد البريد بتحدٍ أحادي الاستخدام قصير العمر، محدود المحاولات وبإجابات عامة متماثلة للحساب الجديد والقائم. لا إرسال قبل تأكيد المستخدم للعنوان والغرض. الهاتف اختياري ولا يطابق حسابًا دون إثبات ملكيته.
6. ربط المسودة بالحساب في معاملة ذرية بعد مصادقة وإثبات الملكية. لا اعتماد على تطابق بريد CV وحده. منع إعادة ربطها أو ربطها بحسابين، وتجديد الجلسة عند الانتقال.
7. بعد الربط تظهر شاشة المراجعة القائمة؛ الموافقة على كل معلومة قبل دمجها. لا نسخ تلقائي أو استبدال ملف مهني سابق.
8. اختبارات عزل مسودتي ضيف وحسابين، وCSRF، وانتهاء الرمز، وإعادة الاستخدام، والتزامن، والحذف، وفشل الفحص، وإعادة الدخول، والأربع لغات؛ ثم تحديث OpenAPI وتوليد عميل الويب واختبار الرحلة على بيئة مخولة.

## حدود التحقق
اختبارات المكونات تحاكي جلسات ضيف/مسجّل وحالات انقطاع الخدمة؛ لا تعادل اختبار CV واقعي ولا تثبت دقة الاستخراج. لا نشر backend أو تعديل إعدادات خادم ضمن هذه الدفعة.
