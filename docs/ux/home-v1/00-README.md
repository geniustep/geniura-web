## المصادر والمرجعية

1. **ملفات مشروع Geniura داخل ChatGPT:** `GENIURA-HOME-EXPERIENCE-MASTER-v1.md` و`00-README.md` إلى `10-DECISIONS.md`، إضافة إلى حزمة UX السابقة. تم الاحتفاظ بالتصور الوظيفي وتوثيق اختلاف النسخ دون اختلاق اعتماد سابق.
2. **الشفرة والعقود القائمة على GitHub:** `app/[locale]` و`features/*` و`contracts/source.json`، تحدد ما هو موجود بالكود، ولا تثبت نجاح التشغيل في الإنتاج.
3. **ميثاق المنتج:** `docs/01-PRODUCT-CHARTER.md` و`docs/02-USER-JOURNEYS.md` و`docs/04-I18N-UX-ACCESSIBILITY.md` و`docs/05-DECISIONS-AND-SCOPE.md`، مرجع المبادئ المؤسسية والخصوصية.

هذا المجلد هو **مرجع تصميم الواجهات الواحد** بعد التدقيق. ملفات MASTER وDOCX وZIP السابقة مراجع تاريخية؛ ما اختلف بينها مسجل في الملف 11.

## القرارات التوثيقية الموحدة

- واجهة عامة تخاطب الباحث أولاً مع مدخل مستقل للشركات، دون شريط بحث ضخم كأولوية أولى.
- بعد الدخول لوحتان منفصلتان بحسب الصلاحيات والسياق؛ `/account` للإعدادات لا لوحة عمل.
- `/{locale}/workspace/*` هو **مقترح المسارات الموحد في الوثائق فقط**، لا مسارات منفذة ولا قرار نهائي قبل مراجعة العقد.
- عنوان Hero العملي: «سيرتك الذاتية بداية. اجعل خبرتك تفتح لك فرصاً جديدة.»؛ عنوان MASTER البديل مسجل للاختبار، ولا يُعد هذا اعتماداً للنشر.
- لا أرقام أو وظائف أو نسب توافق أو شهادات أو شارات موثوقية غير مسندة. التصفح بلا تسجيل والترشح مجاني.
- أربع لغات `ar/fr/en/es`، هوية Nuit والشعار الرسمي دون تعديل، صفحات العمل خاصة غير قابلة للفهرسة أو التخزين المشترك.
- **عقد API موجود لا يعني تشغيل الخدمة**، ووجود الكود لا يعني اجتياز جودة استخراج CV أو المطابقة.

## حدود التسليم

الملفات في هذا المجلد وثائق فقط. لا تعديل لـ`geniura-api` أو واجهة Next.js، ولا تغيير `main` أو الموافقة على نشر الإنتاج. يبدأ التنفيذ بعد موافقة مستقلة وبوابة QA.
