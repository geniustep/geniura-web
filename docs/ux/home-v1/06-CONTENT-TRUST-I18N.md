# 06 — رسائل الواجهة والثقة واللغات

## 1. النصوص العربية لنسخة العمل

| الموضع | النص |
|---|---|
| Hero | «سيرتك الذاتية بداية. اجعل خبرتك تفتح لك فرصاً جديدة.» |
| الوصف | «أنشئ ملفاً مهنياً منظماً، راجع خبراتك ومهاراتك، واستكشف عروض العمل بسهولة.» |
| الزر الأساسي | «أنشئ ملفك المهني» |
| الزر الثانوي | «أنا صاحب عمل» |
| الرابط المساند | «تصفح عروض العمل دون حساب» |
| قسم الوظائف | «أحدث عروض العمل» عند وجود عروض؛ وعند الفراغ «لا توجد عروض منشورة حالياً» |
| لوحة الباحث | «مرحباً بك في مساحتك المهنية» أو «مرحباً، {firstName}» إن توفر الاسم |
| CV يحتاج مراجعة | «راجع المعلومات المستخرجة قبل اعتمادها في ملفك» |
| لوحة المؤسسة | «مساحة التوظيف الخاصة بـ {organizationName}» حين يثبت السياق |
| مؤسسة قيد التحقق | «طلب التحقق من المؤسسة قيد المراجعة» فقط إذا أعاد الخادم هذه الحالة |

**الاختلاف موثَّق:** MASTER يقترح «خبرتك أكثر من سيرة ذاتية.»، بينما `01-PUBLIC-HOME.md` في مصادر مشروع ChatGPT يقترح النص أعلاه. اخترنا الثاني **كعنوان عمل مؤقت**؛ لا نعلن أنه قرار تسويقي نهائي.

## 2. الترجمة

- العربية `ar` افتراضية، ثم الفرنسية `fr` والإنجليزية `en` والإسبانية `es`.
- مراجعة مفهومية لكل لغة داخل `messages/{ar,fr,en,es}.json` مع `pnpm check:messages` عند التنفيذ.
- صياغة فرنسية أولية من مصدر المشروع: «Votre CV est un point de départ. Faites de votre expérience un atout pour de nouvelles opportunités.»
- لغة واجهة المستخدم ليست لغة إعلان العمل بالضرورة؛ احتفظ بلغة الإعلان الأصلية ووسم الترجمة الآلية إن استُعملت.
- أسماء، أرقام، مؤهلات، شركات، تواريخ ومهن مختلطة تُعرض بالاتجاه الصحيح.

## 3. مصطلحات ثابتة

«الملف المهني» = Profil professionnel؛ «الترشح» = Candidature؛ «المؤسسة» = Employeur/Entreprise حسب السياق؛ «عرض عمل» = Offre d'emploi؛ «مراجعة المعلومات المستخرجة» = Révision des données extraites؛ «قيد المعالجة» = En cours de traitement.

## 4. الثقة والصدق في المحتوى

- **التحقق من المؤسسة** لا يساوي **مراجعة الإعلان**. استخدم الشارة فقط بناء على حالة حقيقية.
- الراتب غير المعلن يوسم «غير معلن»، ولا يحل محله رقم صفر أو نطاق مستنتج.
- «نشر مجاني للمؤسسات» غير معتمد تجاريًا؛ لا يُعرض حتى تتضح السياسة وتجهيز الخدمة.
- لا شهادات نجاح، أو عدادات مستخدمين، أو توقيت «نُشر اليوم» أو «نشط الآن» دون مصدر.
- لا استخدام لشعارات عملاء دون إذن أو مصدر معتمد.
- لا ادعاء «مستخرج بالذكاء الاصطناعي وموثوق» قبل نجاح الرحلة المنشورة واجتياز جودة الاستخراج.
- فرّق بين ما صرّح به المستخدم، وما استخرجته الآلة، وما تحقق منه النظام؛ لا ترفض مرشحًا آليًا.
- الترشح مجاني ولا تُشترط دورة مدفوعة لإرساله؛ خصوصية البيانات موضحة قبل المشاركة.

## 5. اختبار الرسالة

اختبر في خمس ثوانٍ: هل فهم الزائر فائدة Geniura؟ هل عرف كيف ينشئ ملفًا أو يتصفح عروضًا بلا حساب؟ هل يستطيع صاحب العمل العثور على مدخله؟ هل يفهم المستخدم متى تُشارك بياناته؟
