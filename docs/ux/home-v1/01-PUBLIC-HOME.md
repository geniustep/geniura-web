# 01 — الواجهة الرئيسية العامة للزائر

**المعرّف:** UX-PUBLIC-001. **المسار القائم:** `/{locale}`. **الجمهور الأول:** الباحث عن عمل؛ **الجمهور الثاني:** المؤسسة.  
**هدف الخمس ثوانٍ:** بيان الفرق الحقيقي لـGeniura وإتاحة إجراء مباشر من دون إيهام بوجود آلاف العروض.

## 1. Hero: القيمة قبل البحث

- التمهيد: «منصة للعمل والكفاءات».
- **عنوان نسخة العمل:** «سيرتك الذاتية بداية. اجعل خبرتك تفتح لك فرصاً جديدة.»
- الوصف: «أنشئ ملفاً مهنياً منظماً، راجع معلومات خبرتك ومهاراتك، واستكشف عروض العمل بسهولة».
- الزر الأساسي: «أنشئ ملفك المهني»؛ للضيف يبدأ مسار التسجيل، وللمسجل يفتح ملفه/مساحة العمل بحسب الصلاحية.
- الزر الثانوي: «أنا صاحب عمل» إلى `/{locale}/employers` العامة، لا إلى لوحة خاصة غير موجودة.
- رابط نصي مستقل: «تصفح عروض العمل دون حساب» إلى `/{locale}/jobs`.
- العنصر البصري: **معاينة توضيحية للملف المهني** (خبرة، تكوين، مهارات، لغات، خصوصية)، موصوفة بوضوح بأنها مثال لا بيانات حقيقية.

لا تُعلن أرقام مستخدمين أو عروض وهمية؛ لا وعود بتوظيف مضمون أو مطابقة 99% أو تحليل سيرة ذاتية بدقة قبل تحقق الجودة. النص بديل MASTER «خبرتك أكثر من سيرة ذاتية.» محفوظ للاختبار، وليس عنوانًا موازيًا منشورًا.

## 2. ترتيب بقية الصفحة

1. **ترويسة ثابتة خفيفة:** الشعار الرسمي، عروض العمل، للمؤسسات، اللغة، تسجيل الدخول/قائمة الحساب. الهاتف: قائمة واضحة وعناصر لمس مناسبة.
2. **ثلاث فوائد عملية:** تنظيم الملف المهني؛ تصفح الوظائف؛ التحكم في ظهور البيانات.
3. **أحدث العروض الحقيقية:** 3–6 بطاقات فقط من API، العنوان والمؤسسة والمدينة ونوع العمل والراتب **إذا أعلن** وحالة النشر وتاريخه الحقيقي. عند قلة البيانات لا تتكرر البطاقات.
4. **كيف تعمل المنصة:** أنشئ ملفك ← راجع معلوماتك وحدد المشاركة ← استكشف الفرص وتقدم عند الرغبة.
5. **الدعوة للمؤسسات:** «هل تبحث عن كفاءات؟» مع رابط إلى صفحة المؤسسات العامة؛ لا «انشر مجاناً الآن» قبل قرار تجاري وتنفيذ فعلي.
6. **الثقة والخصوصية:** الترشح مجاني؛ لا اطلاع على ملف خاص دون أذون؛ التحقق من **هوية الشركة** منفصل عن فحص **إعلان الوظيفة**.
7. **التذييل:** سياسات الخصوصية والشروط والمساعدة واللغات، من دون ادعاء تراخيص أو شركاء غير مؤكدين.

## 3. الحالات والتفاعل

| الحالة | العرض |
|---|---|
| لا وظائف | عبارة صادقة ومقترح لإنشاء الملف أو متابعة البحث؛ لا عناصر demo |
| نتائج قليلة | عرض الموجود وحده، من دون ملء اصطناعي |
| تعطل API الوظائف | يبقى Hero وروابطه صالحين، وتظهر رسالة خطأ محلية |
| مستخدم مسجل | لا إعادة توجيه إجبارية من الصفحة العامة؛ رابط لمساحة عمله عند الجاهزية |
| رفع CV مغلق/متوقف | إنشاء الملف يدويًا متاح؛ لا وعد برفع آلي |
| زائر يريد التقدم من إعلان | يحفظ المقصد الآمن بعد الدخول، ولا يرسل طلبًا تلقائيًا |

## 4. المطابقة مع الكود ومقياس النجاح

الـHero الحالي في `app/[locale]/page.tsx` يقود بالبحث؛ الوثيقة تطلب **تغيير ترتيب**، وليس وصف واجهة منفذة. `features/home/latest-jobs.tsx` يجلب أحدث وظائف حقيقية ويعالج الفراغ/التعطل؛ يستفاد منه.

القياس: زيارات مؤهلة ← بدء إنشاء الملف ← إكماله، فتح العروض، دخول صفحة المؤسسات؛ لا تساوِ بين النقر والنتيجة. لا إرسال أسماء أو CV إلى التحليلات.

**بوابة القبول:** أربع لغات وRTL/LTR، هاتف 320px فأكثر، CTA صحيح، وظائف عامة بلا حساب، SEO/OG/structured data صادقة، لا تغيير الفهرسة من دون موافقة.
