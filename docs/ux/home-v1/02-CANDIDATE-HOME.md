# 02 — الواجهة الرئيسية للباحث بعد الدخول

**المعرّف:** UX-CANDIDATE-001. **المسار المقترح:** `/{locale}/workspace/candidate` (غير موجود حالياً).  
**الوعد:** «أعرف ما الذي ينبغي أن أفعله الآن، وما وضع ملفي وترشيحاتي».

## 1. الصفحة مساحة عمل لا إعلان

تُعرض **مهمة واحدة رئيسية** مرتبطة بحالة المستخدم الفعلية، لا شريط بحث كبير أو نسبة "جودة المرشح". تظهر تحية آمنة ثم بطاقة الإجراء التالي، يليها الملف المهني، والسيرة الذاتية، والترشيحات، والعروض العامة.

## 2. ترتيب الأولوية

| حالة فعلية | الإجراء |
|---|---|
| جلسة غير صالحة | إعادة دخول مع `next` داخلي آمن |
| بريد غير مؤكد عند حاجة العملية للتحقق | تنبيه ورابط إعادة التأكيد إن كان متاحًا |
| CV يحتاج مراجعة `review_required` | «راجع المعلومات المستخرجة»؛ لا اعتماد تلقائي |
| CV قيد المعالجة | حالة معالجة فعلية دون مدة مخترعة |
| فشل استخراج CV | شرح مع التحرير اليدوي دون فقد البيانات |
| ملف مهني لم يبدأ | «ابدأ ملفك المهني» |
| ملف بدأ ولم يكتمل | فتح القسم الناقص الذي ثبت من البيانات |
| لا إجراءات ملحة | «استكشف عروض العمل» |

تحذيرات أمن الحساب أو الموافقات الحساسة لا تُخفى خلف توصيات وظيفية. لا يُجبر من يبني ملفه يدوياً على رفع CV.

## 3. عناصر الشاشة

- **بطاقة الملف:** التعريف والهدف المهني، الخبرة، التكوين، المهارات، اللغات، الشهادات، التوفر والتفضيلات بحسب العقد؛ لا نسبة مئوية عامة لـ«قيمة الشخص».
- **السيرة الذاتية:** حالات الرفع والفحص والاستخراج والمراجعة والنسخة الأساسية؛ روابط تعيد إلى `/account/profile/resumes` والمسار الحالي للمراجعة.
- **الترشيحات:** آخر ثلاث طلبات إن كانت الخدمة تختبر وتعمل، مع الوظيفة والمؤسسة والتاريخ والحالة الحقيقية `submitted/in_review/shortlisted/interview/offer/hired/rejected/withdrawn/closed` وفق الخادم. لا عرض «تمت القراءة» إلا بحدث مُصرَّح به.
- **الفرص:** أحدث عروض حقيقية أو نتائج بحث؛ لا تُسمى «مطابقة ذكية» قبل إثبات تفسير المطابقة وجودتها.
- **الخصوصية:** حالة ظهور الملف وأذون المشاركة، وسجل الاطلاع حيث تسمح سياسة المشاركة، وروابط إعدادات الحساب.

## 4. بيانات ونطاق مُثبت بالكود

`/account` الحالي لإعدادات المستخدم. `/account/profile` و`features/profile` لديهما عناصر الملف ومراجعة CV؛ **يُعاد استعمالهما** دون نسخ محرك الاستخراج في Dashboard. `GET /api/v1/candidates/me/applications` و`GET /api/v1/candidates/me/interviews` موجودتان في عقد الواجهة وعميل Orval، لكن وجود العقد لا يثبت توفر قائمة واجهة أو نجاح الإنتاج.

نموذج الدخول الحالي يستعمل `safeRedirectPath(next)` بقيمة احتياطية `/account`؛ لا يدّعي النص أن تحويل المستخدم تلقائيًا إلى `/workspace/candidate` منفذ.

## 5. الحالات الحرجة

- لا ترشيحات: رسالة صادقة مع رابط للبحث، وليس جدولاً وهمياً.
- فشل API: خطأ محلي وإعادة المحاولة؛ **لا تعتبر الخطأ صفرًا**.
- نتيجة CV `failed`: التحرير اليدوي متاح، ولا تفقد المعلومات المحفوظة.
- اختلاف تعديل `If-Match` / 412: احترام حماية النسخة الأحدث.
- متعدد الأدوار: تبديل مساحة العمل بأذونات ثابتة من الخادم.
- بيانات المرشح: `noindex` و`private,no-store` والتفويض من الخادم، لا cache مشترك.

## 6. قبول التجربة

جديد بلا CV، ملف ناقص، CV قيد المعالجة، مراجعة، فشل، لا ترشيحات، ترشيحات حقيقية، انتهاء جلسة، و403/412/503، مع تجربة RTL/LTR ونافذة هاتف، ودون تفعيل مطابقة غير مُثبتة.
