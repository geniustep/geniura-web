# ADR 0003 — الوظائف العامة والبحث وSEO

- التاريخ: 2026-10-17 — الحالة: Accepted (technical). يعتمد على العقد الحالي geniura-api@239ebd9.

## القرار
- **الصفحات:** `/[locale]/jobs` (بحث وفلاتر) و`/[locale]/jobs/[jobId]` (تفاصيل). الروابط بالمعرّف UUID إلى أن
  يوفر الـAPI حقل `slug` (البند 6 في `docs/07-BACKEND-COORDINATION.md`).
- **حالة البحث في URL** عبر nuqs (محللات مشتركة بين الخادم والمتصفح في `lib/jobs/search-params.ts`). القيم تُطبَّع
  وتُحدّ (طول النص 200، معرّفات UUID فقط، صفحات ≤ 200، `page_size` = 20) فتصلح مفتاحَ تخزين.
- **التخزين المؤقت (عام فقط):** `lib/api/public.ts` بـ `'use cache'`: نتائج البحث وتفاصيل الوظيفة `cacheLife("minutes")`
  والقواميس `cacheLife("hours")`، بوسوم `jobs` و`job:<id>` و`taxonomy` جاهزة لإبطال لاحق عبر webhook (البند 8).
  لا Cookie ولا هوية مستخدم في أي من هذه الدوال. الأخطاء لا تُخزَّن.
- **التسميات:** الـAPI يعيد المدينة/المهنة/القطاع/المهارة كمعرّفات فقط ولا يتيح البحث بالمعرّف؛ مؤقتًا تُستعمل أول 50
  قيمة من كل قاموس (تكفي القاموس الحالي) مع تسمية محايدة لما لا يُعرف. الحل الدائم: تسميات مضمّنة (البند 7).
- **الفلاتر:** قوائم أصلية `<select>` (أفضل للوحة المفاتيح وقارئ الشاشة والهاتف)؛ على الهاتف داخل درج مطوي.
- **حالة HTTP:** الصفحات ترسل قشرتها الثابتة فورًا، فلا تستطيع التحول إلى 404 بعد البدء. لذلك يتحقق `proxy.ts`
  من وجود الوظيفة قبل العرض (ذاكرة 60 ثانية داخل العملية) ويحوّل المجهولة/المنتهية إلى صفحة 404 المترجمة بحالة 404
  حقيقية. عند تعذر الوصول إلى الـAPI تُعرض الصفحة وتشرح المشكلة بدل ادعاء أن الوظيفة غير موجودة.
- **SEO:** JobPosting JSON-LD في صفحة التفاصيل فقط (`validThrough`، `datePosted`، `hiringOrganization`، `jobLocation`
  أو `TELECOMMUTE`، `baseSalary` بالدرهم، `directApply: false` حتى يتاح الترشح). canonical نحو لغة الإعلان
  الأصلية. sitemap ديناميكي بالوظائف المنشورة فقط. الفهرسة كلها ما زالت معطلة (`NEXT_PUBLIC_ALLOW_INDEXING=false`).
- **الإبلاغ:** نموذج بلاغ مجهول عن الإعلان (`POST /api/v1/reports`)؛ القرار لفريق الثقة.
- **الترشح:** الزر معطل مع تنبيه «لا تدفع مقابل الترشح» إلى PHASE 4.

## مؤجل
- البحث المحفوظ والتنبيهات وfacets (تحتاج endpoints جديدة).
- صفحات المدن/المهن البرمجية (عتبة الجودة قرار منتج).
- Indexing API من جهة Django.
