# Geniura Web

واجهة Next.js متعددة اللغات لمنصة Geniura. **الحالة: تأسيس تقني أولي على `dev`، غير معتمد للإنتاج.**

المستودع العام للواجهة فقط. النظام الخلفي وقواعد الأعمال والبيانات الحساسة في `geniustep/geniura-api` الخاص.

## التشغيل المحلي
- Node.js 22
- `npm install`
- `cp .env.example .env.local`
- `npm run dev`
- زيارة `http://localhost:3000/ar` أو `http://localhost:3000/fr`

قد يعيد API العام رسالة صيانة 503؛ عندها تعرض الواجهة رسالة عدم التوفر بدل اختلاق وظائف.

## فحوص الجودة
`npm run lint` و`npm run typecheck` و`npm run build`.

**ملاحظة:** لم يتوفر npm registry في بيئة التأليف، ولذلك لم يُولَّد `package-lock.json` ولم تُنفذ فحوص npm هنا. يُطلب إصدار lockfile في بيئة متصلة ثم التحول إلى `npm ci` قبل اعتماد النشر.

## الحدود
- لا اتصال مباشر بقاعدة البيانات أو أسرار في `NEXT_PUBLIC_*`.
- لا نسخ لنماذج الأذون أو قرار المطابقة إلى Next.js.
- لا عرض لملفات CV أو بيانات المرشحين الخاصة في صفحات عامة.
- لا تخزين مؤقت للبيانات المرتبطة بجلسة مستخدم.
- `main` للإصدار المعتمد، و`dev` للتطوير.
- لا يتم تشغيل Vercel Production ضمن هذا العمل.
